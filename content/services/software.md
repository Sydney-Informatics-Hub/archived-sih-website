### Scikit-learn

The Sydney Informatics Hub sponsors development of the popular
[Scikit-learn](http://scikit-learn.org) machine learning library and related
tools within the Scientific Python framework.  This helps give back to
open-source projects that we rely on, while maintaining expertise within the
team.

### Bayes Spec

An implementation of methods for spectral analysis using the Bayesian framework in the statistical programming language R. It includes functions for modelling spectrum as well as appropriate plotting and output estimates. There is segmentation capability with RJ MCMC (Reversible Jump Markov Chain Monte Carlo). The package takes these methods predominantly from the 2012 paper ["AdaptSPEC: Adaptive Spectral Estimation for Nonstationary Time Series"](https://doi.org/10.1080/01621459.2012.716340).

- [Cran repository](https://cran.r-project.org/web/packages/BayesSpec/index.html)
- [Git repository](https://github.com/ctds-usyd/BayesSpec)

## Bioinformatics Software

### CLC Genomics

CLC Genomics Workbench is a comprehensive suite of bioinformatics tools packaged into a user-friendly graphical environment. The Workbench is also backed by a dedicated server and will be connected with the Artemis HPC in 2018. CLC is offered at a heavily discounted rate subsidised by the University. Single licences are currently $750 (incl. GST) for a 6 month or $1,500 (incl. GST) for a 12 month subscription. A single license may be shared amongst a research group, however only one user from the group can use the license at any one time. Subscribers can book one of 11 university licenses using the [Sydney Informatics Hub PPMS](https://au.ppms.info/sydney/login/?pf=6). Please note, if you are using a license which someone else has booked, the SIH can terminate your session, so please do use the booking system.

Please email our bioinformatics technician at [sih.info@sydney.edu.au](mailto:sih.info@sydney.edu.au) for more information on CLC Genomics Workbench or to request a free trial.

Download CLC Genomics workbench directly from Quiagen for [Mac](http://download.clcbio.com/CLCGenomicsWorkbench/10.1.1/CLCGenomicsWorkbench_10_1_1.dmg), [Windows](http://download.clcbio.com/CLCGenomicsWorkbench/10.1.1/CLCGenomicsWorkbench_10_1_1_64.exe), and [Linux](http://download.clcbio.com/CLCGenomicsWorkbench/10.1.1/CLCGenomicsWorkbench_10_1_1_64.sh)

### Ingenuity Pathway Analysis

Ingenuity® Pathway Analysis (IPA®) is a powerful analysis and search tool that uncovers the significance of ‘omics data and identifies new targets or candidate biomarkers within the context of biological systems. IPA has broadly been adopted by the life science research community and is cited in thousands of articles for the analysis, integration, and interpretation of data derived from ‘omics experiments, such as RNA-seq, small RNA-seq, microarrays including miRNA and SNP, metabolomics, proteomics, and small scale experiments.

The University has one IPA license that is available free of charge to Sydney University students, researchers, and affiliates and can be booked using the [Sydney Informatics Hub PPMS](https://au.ppms.info/sydney/login/?pf=6). Log into IPA at [https://www.qiagenbioinformatics.com/product-login/](https://www.qiagenbioinformatics.com/product-login/).

The [Qiagen Bioinformatics](https://www.qiagenbioinformatics.com/ipa-training/) website has a set of training resources. The most popular webinars are:

* [IPA Introduction](http://tv.qiagenbioinformatics.com/video/14439964/introduction-to-ingenuity-pathway-analysis-ipa-1)
* [Data Formatting and uploading](http://tv.qiagenbioinformatics.com/video/14531154/interpreting-the-results-of-your-core-analysis)
* [Interpreting the results](http://tv.qiagenbioinformatics.com/video/14531154/interpreting-the-results-of-your-core-analysis)

Please email our Bioinformatics Technician at [sih.info@sydney.edu.au](mailto:sih.info@sydney.edu.au) for more information on IPA.
